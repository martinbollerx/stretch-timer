# Stretch Timer

A single-file web app that guides you through a short stretching routine.

- 5 stretches: Pancake, Figure 4, Hip Flexor, Chest Stretch, Lat Stretch
- 30-second holds, 10-second breaks, 5 seconds to get ready at the start
- Two reps per stretch (both reps on one side, then the other side)
- Ring countdown, progress list, optional beeps, keeps the screen awake while running
- Light and dark mode, works on phones

Everything is in `index.html`. The only external resource is Google Fonts. There is nothing to build or install: open the file in a browser, or use the live version on GitHub Pages.
